Le contrat

Trois champs décident de tout.

service

Ce que vous envoyez. Un seul crédit, facturation par canal utilisé.

smswhatsappotp
channel

Par où ça part. Même campagne, chaque canal avec sa validation.

smswhatsapp
country

Où ça part. Les 54 pays d'Afrique, code ISO à deux lettres.

OTP via API

WhatsApp d'abord. SMS si besoin.

Votre application appelle l'API avec le numéro de votre utilisateur : le code part sur WhatsApp, avec repli SMS s'il n'est pas reçu. Vous payez les canaux réellement utilisés ; le message WhatsApp est servi si vous disposez d'unités WhatsApp.

Statuts

Chaque message, suivi de bout en bout.

Chaque étape est horodatée, consultable dans l'espace client et transmise par webhook.

StatutCe que ça veut dire
EnregistréLe message est accepté et placé dans la file d'envoi.
Pris en chargeL'opérateur a reçu le message.
EnvoyéLe message est parti sur le réseau.
LivréL'accusé de réception est revenu du téléphone.
ÉchouéLe message n'a pas pu être remis, avec le motif exact.
